
# TaskFlow

TaskFlow is a simple Flutter task management application with a clean
white, black and blue user interface.

## Features

- View all tasks
- Add new tasks
- Mark tasks as completed
- Delete tasks
- View total, completed and pending task counts

## Technology

- Flutter
- Dart
- Material Design 3

## How to Run

1. Open the project in FlutLab.
2. Run Pub Get.
3. Select the Web platform.
4. Build and launch the Web Emulator.

## Note

This basic version stores tasks in application memory.
Tasks reset when the application is restarted.
