
# TaskFlow

TaskFlow is a simple Flutter task management application with a clean
white, black and blue user interface.

## Features

User registration and login using email and password
- Secure logout
- View all tasks
- Add new tasks with a title and description
- Edit existing tasks
- Mark tasks as completed or pending
- Delete tasks
- Automatically update total, completed and pending task counts
- Store and retrieve tasks from a cloud database
- Real-time task data synchronisation
- Secure user-specific task access

## Technology

- **Frontend:** Flutter and Dart
- **UI:** Material Design 3
- **Backend:** Supabase
- **Database:** Supabase PostgreSQL
- **Authentication:** Supabase Authentication
- **Real-time Updates:** Supabase Realtime
- **Version Control:** Git / GitHub

## How to Run

1. Open the project in FlutLab.
2. Run Pub Get.
3. Select the Web platform.
4. Build and launch the Web Emulator.

## Note

This basic version stores tasks in application memory.
Tasks reset when the application is restarted.
